# Stockfish engine

`stockfish.asm.js` is the unmodified pure-JavaScript build of Stockfish 10 from the
[`stockfish` npm package, version 10.0.2](https://www.npmjs.com/package/stockfish/v/10.0.2)
(source: https://github.com/nmrugg/stockfish.js, based on https://github.com/official-stockfish/Stockfish).

available at the links above.
